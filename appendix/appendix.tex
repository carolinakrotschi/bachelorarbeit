\chapter{Use of Artificial Intelligence Tools}
\thispagestyle{empty}

For transparency, this section describes how artificial intelligence tools were used during the preparation of this thesis.

Claude Code, Gemini, and ChatGPT were used to improve the fringe-counting software. They helped with finding and fixing programming errors, making the code more robust, and adding safety checks in order to prevent the expensive hardware from damage. The main code structure and the underlying logic were developed by the author.

These tools were also used to improve the wording and readability of parts of the written text, proofreading and language suggestions.  They were not used to independently create scientific content or citations.
